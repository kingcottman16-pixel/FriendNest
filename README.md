# FriendNest

FriendNest is a browser-based social/support app prototype.

## Run locally
1. Install Node.js.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000

## Deploy
Deploy the project as a Node.js web service. Start command: `node server.js`.

## Important
This starter stores data in server memory, so accounts/messages reset when the server restarts. For a real production service, use a persistent database, secure JWT secret, rate limiting, moderation/reporting, email verification, password reset, backups, and privacy/security review.
